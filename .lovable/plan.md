

## الخطة: تصميم صفحة تفاصيل منتج مخصصة لهلا جملة

### ما سيتم بناؤه

صفحة تفاصيل منتج جديدة خاصة بقسم هلا جملة (بدل استخدام `ProductDetail` العادية) تحتوي على:

1. **عرض المنتج بالكامل** - صور، وصف، أبعاد، وزن، SKU
2. **الدول المتاحة مع الاستوك** - عرض كل دولة مع حالة التوفر
3. **أقل طلب (MOQ)** - عرض الحد الأدنى للطلب
4. **فورم طلب المنتج** يشمل:
   - اختيار الدولة (من الدول المتاحة للمنتج فقط)
   - حقل الكمية (مع التحقق من MOQ)
   - حقل ملاحظات
   - زر إرسال الطلب

### التغييرات التقنية

#### 1. إضافة حقل MOQ للبيانات
- تحديث `Product` interface بإضافة `minOrder?: number`
- إضافة قيم MOQ لمنتجات الجملة في `wholesaleProductsData.ts`

#### 2. إنشاء كومبوننت جديد `WholesaleProductDetail.tsx`
- تخطيط RTL بالكامل مع ثيم برتقالي (accent)
- **القسم العلوي**: معرض صور + معلومات المنتج الأساسية (اسم، سعر، SKU، وزن، أبعاد، وصف)
- **قسم الدول والاستوك**: كروت لكل دولة متاحة مع شارة التوفر
- **قسم أقل طلب**: عرض الحد الأدنى بشكل بارز
- **فورم الطلب**: Select للدولة (من `product.countries`)، input للكمية مع validation على MOQ، textarea للملاحظات، وزر إرسال بلون accent يعرض toast عند الإرسال

#### 3. تحديث `Wholesale.tsx`
- استبدال `ProductDetail` بـ `WholesaleProductDetail` عند الضغط على منتج

### الملفات المتأثرة
- **إنشاء**: `src/components/wholesale/WholesaleProductDetail.tsx`
- **تعديل**: `src/data/productsData.ts` (إضافة `minOrder?` للـ interface)
- **تعديل**: `src/data/wholesaleProductsData.ts` (إضافة قيم MOQ)
- **تعديل**: `src/pages/Wholesale.tsx` (استخدام الكومبوننت الجديد)
